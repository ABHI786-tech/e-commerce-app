About This Project

Mega Store is a simple e-commerce web application created to understand how real-world websites work. The main focus of this project is learning frontend development concepts by building features step by step.

While working on this project, I learned how to design responsive user interfaces using HTML, CSS, and Bootstrap. I also practiced using JavaScript to handle dynamic data, user interactions, and browser storage.

This project helped me understand important concepts like:

  • Creating reusable layouts like navbar and footer
  • Fetching data from APIs and displaying it dynamically
  • Using localStorage for cart and login management
  • Handling user authentication with tokens
  • Basic error handling and UI feedback

The goal of this project was not to make everything perfect, but to learn by building and fixing problems step by step. Each page of this application helped me improve my understanding of frontend logic and UI structure.

* This project is built for learning purposes and to showcase practical frontend skills.
